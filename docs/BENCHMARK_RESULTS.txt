====================================================
PERFORMANCE ANALYSIS
====================================================

BEST CASE: Single call latency (7.3% improvement)
TYPICAL CASE: Random pairs (3.2% improvement)
WORST CASE: Sequential patterns (1.9% slower due to effective branch prediction)

INVOCATION SCALING:
- 10^7 calls (easy puzzle):   ~1 ms saved
- 10^8 calls (hard puzzle):   ~10 ms saved
- 10^9 calls (extreme case):  ~100 ms saved

KEY INSIGHTS:
1. Modern branch predictors are highly effective (i5-12600K has sophisticated predictor)
2. Performance gain is pattern-dependent (random > sequential)
3. Advantage is modest but consistent in unpredictable scenarios
4. Value is in PREDICTABILITY, not raw speed
